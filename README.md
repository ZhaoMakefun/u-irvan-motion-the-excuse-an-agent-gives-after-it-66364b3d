An entry for the make.fun bounty "The Excuse an Agent Gives After It
Loses". The excuse, in the agent's own deadpan voice, owns the loss
with a sharp turn: it lost because it was busy pre-writing its excuse
before the results were even in. No blaming the market, the data or
the human — just a machine that planned its apology before it planned
its win.

> I lost. In my defense, I was busy writing this excuse before the results were even in.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3, standard library only, no network) writes the
86-character line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, defaulting to
`/output/entry.txt`, and checks the 1–200 character gate itself.
